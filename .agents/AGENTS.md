# Dynime ERP Design System & UI Directives

## Border Radius Directive
- **Subtle & Standard Corner Radius**: Always use standard, clean border radii matching the Dynime ERP design system (`rounded-lg` / `rounded-xl` for cards, `rounded-lg` / `rounded-md` for buttons and inputs, `rounded-md` for badges and small tags).
- **Avoid Oversized Curves**: NEVER use overly large curves like `rounded-3xl` or `rounded-2xl` on standard cards, containers, buttons, or inputs unless explicitly requested for circular avatars.
